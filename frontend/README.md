# CivicPulse Operator Dashboard

React + TypeScript + Vite frontend for the CivicPulse operator dashboard.

Setup, environment variables, demo credentials and the manual testing walkthrough are
documented in the [root README](../README.md#7-frontend-setup-react-operator-dashboard).

```bash
cp .env.example .env   # VITE_API_BASE_URL=http://localhost:8000/api
npm install
npm run dev            # http://localhost:5174
npm run lint
npm run build
npm test
```
